## Top 3 lessons

1. **The round unit changed from one axis-move to 1–3 claims, with new claim types.**
   [`AXES.md`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/skills/shokunin/protocol/AXES.md),
   [`PROTOCOL.md`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/skills/shokunin/protocol/PROTOCOL.md),
   [`MISSION.md`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/skills/shokunin/protocol/MISSION.md)
   and [`commands/shokunin.md`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/commands/shokunin.md)
   now require causally separable claims on distinct axes (one on the lowest non-retired axis unless the
   new stagnation nudge waives it). Two additions widen what counts as progress without loosening
   evidence: a `capabilities:` repertoire table (rows enter only with a running demo), and at most one
   *exploratory* claim that verifies only as `unprovable-but-better` with a named non-author reviewer.
   Rounds also get three trend verdicts (expansion / quality / discernment) from
   [`LEARNING.md`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/skills/shokunin/protocol/LEARNING.md).
   This is the biggest depth gain to date: the contract can now reward craft and repertoire, not just counts.

2. **Curation became a machine-checked contract.** `CORPUS.md` gains SOURCES contract v1
   (11-column registry, scoped A/B/C tiers, `community` never A, append-only, a row is written only
   after the source is opened, search log, no credentials) plus a `## Mistakes` lesson duty and
   "show the fix can fail first". The new
   [`scripts/sources-census.sh`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/scripts/sources-census.sh)
   (806 lines) implements census / validate (E01–E12, W01–W04) / overdue / shared / selftest, with
   fixtures under `scripts/fixtures/sources-census/` (including an injection fixture), and
   [`install.sh`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/install.sh) now gates on them.
   The mint kit seeds an empty
   [`templates/mint/corpus/SOURCES.md`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/templates/mint/corpus/SOURCES.md).
   Calibration note: the watchdog's `sources_gate` *skips with a warning* when the census script is
   missing or returns an unexpected code, so the gate fails open in those cases.

3. **Authority flipped: this repo is now canonical, and the driver got sturdier.** The README's
   Provenance section now says this repo's protocol governs and the private fleet root is a downstream
   vendor that records the canonical revision it copies (sync pinned to fleet revision `dcf3b64…`).
   [`shokunin-watchdog.sh`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/scripts/shokunin-watchdog.sh)
   runs each lane under `setsid` in its own process group, verifies liveness via `/proc` env tags,
   escalates TERM→KILL without advancing on failure, and logs Sources & frontier conformance.
   Config is now read once at startup with `<id>|<repo>|<axes>` rows and no per-lane route field.
   Two accuracy gaps to fix: `README.md` and `MISSION.md` say `SHONOKIN_ROOT`, while every script and
   `shokunin.conf.example` use `SHOKUNIN_ROOT`; and the commit is authored `ci <ci@shokunin.local>`
   rather than a lane identity, which sits awkwardly next to "lane identity rides in every commit".
   The big README rewrite also leaves PR #1 and the seven README branches further behind and likelier to conflict.
