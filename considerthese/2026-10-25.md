## Top 3 lessons

1. **Running the census exposed a dependency that reading never did.** On a box without `gawk`,
   `sources-census.sh selftest` exits 2 with `ERROR: --today not an ISO date: 2026-10-25`: the
   `iso_epoch` helper ([`scripts/sources-census.sh`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/scripts/sources-census.sh)
   lines 49–56) shells out to `gawk`, the call fails, and the failure is reported as a bad date.
   `rg -i gawk README.md install.sh skills commands templates` finds no mention of the dependency.
   After installing `gawk`, `selftest ok` (exit 0), so the script itself is sound. Worth checking
   (unverified hunch) how the watchdog's fail-open `sources_gate` treats this exit-2 path on a host
   without `gawk`.
2. **SOURCES.md is enforced; the rest of the corpus contract is not.** The census validates every
   `SOURCES.md` rule that can be mechanized (E01–E11, including missing `used-by` paths), and its
   selftest passes. But `CORPUS.md` §Additional corpus rules says "Freshness sweeps read" each
   knowledge entry's `source:` / `verified-at:` / `recheck:` fields, and no script reads them
   (`rg -n verified-at scripts` → 0 matches; the only freshness reference in `scripts/` is the
   watchdog's report-acceptance log line). The mint template ships empty `corpus/knowledge/` and
   `corpus/lessons/` folders, so there is no example of a conforming entry either.
3. **The contract's evidence can't be followed from the published plugin.** `CORPUS.md` cites
   `.ufo/reports/round-2/AGGREGATE.md`, and
   [`PROTOCOL-APPENDIX.md`](https://github.com/VeigaPunk/kimi-shokunin/blob/main/skills/shokunin/protocol/PROTOCOL-APPENDIX.md)
   rows "Corpus sources" and "Frontier step" cite `.ufo/waves/...` on branch `kaika/ledger` and a
   `verify-protocol.sh`. This repo has no `.ufo/` directory, no `kaika/ledger` branch, and no
   `verify-protocol.sh` (`ls -d .ufo`, branch list, `rg verify-protocol`). They live in the fleet
   root, which is fine internally, but the plugin's own "a negative claim carries its sweep" rule
   can't be checked by a reader of this repo. A one-line note saying where the fleet root lives
   would close it.
